# Project Copy

## Short GitHub description

Five-season NBA geospatial analysis measuring how travel, time zones, rest, schedule density and altitude relate to game performance.

## LinkedIn project description

Built a five-season geospatial analysis of 6,000 NBA regular-season games and 12,000 team-game observations to test whether schedule geography is associated with performance. Created an original outcome-independent Schedule Friction Index using travel distance, time-zone shifts, rest deficit, seven-day game density, road-trip length and altitude gain. Used Python, pandas, geospatial distance modeling and fixed-effects regression to compare relative schedule burden within matchups while controlling for recent team strength, season and team effects. The primary model found that a +1 unit increase in relative schedule friction was associated with a 1.35-point lower game margin and roughly a 4.0-percentage-point decrease in predicted win probability.

## Resume bullet

Built a Python geospatial model across 6,000 NBA games (12,000 team-game observations), creating an original Schedule Friction Index from travel, time-zone, rest, density and altitude data; fixed-effects modeling linked a +1 relative-friction increase with a 1.35-point lower margin (p<0.001).

## Interview explanation

I wanted to connect my interest in basketball with what I study in Geospatial Data Science and Economics. Instead of predicting winners directly, I treated the NBA schedule as a spatial exposure problem. I reconstructed where teams were before each game, estimated travel and time-zone changes, added recovery and schedule-density variables, and combined them into an outcome-independent index. Then I compared the two teams' schedule burden within each matchup and controlled for recent form and fixed team/season differences. The point was less about building a betting model and more about asking whether geography creates a measurable performance tax.
